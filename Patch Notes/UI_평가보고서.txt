1. 메인 로비 (index.html)

  [잘 된 점]
  - 좌우 50/50 분할 레이아웃으로 시각적으로 명확한 구조
  - 왼쪽 틸(teal) 그라디언트 + 흰색 텍스트로 브랜드 아이덴티티 명확
  - "새 방 만들기" 버튼이 크고 눈에 잘 띔
  - 게임 컨트롤러 이모지 바운스 애니메이션으로 생동감

  [개선이 필요한 점]
  - 오른쪽 영역이 버튼 하나만 있어서 너무 허전함.
    게임 미리보기나 플레이어 수 등 추가 정보 없음. (우선순위: 높음)
  - 메인 로비에서 어떤 게임을 만들지 미리 선택하는 UI가 없음. (우선순위: 중간)
  - "지금 게임을 플레이 하세요!"가 두 줄로 나뉘어 보임. (우선순위: 낮음)


----------------------------------------------------------------

2. 대기방 (game.html - 로비 화면)

  [잘 된 점]
  - 좌우 2-컬럼 레이아웃(게임 영역 + 사이드바)이 균형적
  - 이모지 폭죽 팔레트바가 하단에 고정되어 재미 요소로 잘 작동함
  - "초대 링크 복사" 버튼이 눈에 띄는 파란색으로 잘 배치됨
  - 참여자 목록 + 채팅 기록 사이드바의 정보 밀도 적절

  [개선이 필요한 점]
  - 빙고/라이어 투표 버튼이 비활성화되어 있지만
    왜 안 되는지 안내 문구가 없음.
    "방장이 투표 시작 버튼을 눌러야 활성화됩니다" 같은 설명 필요. (우선순위: 높음)
  - "다음 게임 투표" 박스와 "어떤 게임을 할까요?" 선택 버튼이
    동시에 표시되어 역할이 중복처럼 보임. (우선순위: 높음)
  - 빙고/라이어/개발중 버튼 크기와 스타일이 일정하지 않음. (우선순위: 중간)
  - 상단의 방장 표시가 작고 눈에 잘 안 띔. (우선순위: 낮음)


----------------------------------------------------------------

3. 빙고 방장 설정 화면

  [잘 된 점]
  - 설정 항목들(승리 조건, 시작 순서, AI 주제 입력, 턴 제한 시간)이 논리적 순서로 배치
  - "주제 생성 및 시작!" 버튼이 초록색으로 강조되어 핵심 액션 명확

  [개선이 필요한 점]
  - "대기실로 돌아가기" 버튼이 스타일이 없는 밋밋한 기본 버튼처럼 보임.
    아웃라인 버튼 등으로 개선 필요. (우선순위: 높음)
  - 승리 조건 라디오 버튼이 브라우저 기본 스타일로 구식.
    카드 또는 토글 버튼 방식으로 개선 가능. (우선순위: 중간)
  - AI 주제 입력 후 어떤 결과가 만들어지는지 미리보기나 예시 없음. (우선순위: 낮음)
  - 설정 컨테이너 배경과 메인 배경 구분이 없어 시각 깊이 부족. (우선순위: 낮음)


----------------------------------------------------------------

4. 라이어 게임 설정 화면

  [잘 된 점]
  - 간결한 설정(목표 승수 드롭다운)으로 진입 장벽 낮음
  - "시작" 버튼이 크고 초록색으로 명확

  [개선이 필요한 점]
  - 설정 항목 이후 화면 아래 절반이 텅 비어 있어 어색함.
    "게임 준비 중입니다." 텍스트만 달랑 있음. (우선순위: 높음)
  - 라이어 게임이 처음인 플레이어에게 규칙 설명 전혀 없음.
    간단한 How-to 카드가 있으면 좋음. (우선순위: 중간)
  - "대기실로 돌아가기" 버튼 스타일 문제 (빙고와 동일). (우선순위: 높음)
  - 게스트가 이 화면을 보면 아무런 인터랙션이 없어 대기 경험이 단조로움. (우선순위: 중간)
