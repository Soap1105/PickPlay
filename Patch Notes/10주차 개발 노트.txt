[PickPlay] 10주차 개발 노트 (2026-05-06 ~ 2026-05-07)

오늘의 주요 업데이트 사항: 폭탄 돌리기 서바이벌 시스템 개편 및 UI 최적화

1. 폭탄 돌리기 (Bomb Mode) 대규모 개편
   - 생존형 하트 시스템 도입: 기존 점수제에서 벗어나 설정된 하트(1~3개)를 모두 소진하면 탈락하는 서바이벌 방식으로 전환.
   - 전략 서바이벌(Tactical Mode) 추가:
     * 지목(Targeting): 단어 뒤에 플레이어 번호를 입력(예: 사과 2)하여 특정 대상을 공격 가능.
     * 반사(Reflect): 폭탄을 받은 후 2초 이내에 정답 입력 시 공격자에게 즉시 반격.
   - UI/UX 고도화:
     * 점수 표시를 하트 아이콘(❤️)으로 변경하여 시각적 직관성 강화.
     * 플레이어 타겟 번호를 식별하기 쉬운 배지 형태로 디자인 개선.
     * 대기실에서는 하트와 번호를 숨겨 깔끔한 화면 유지, 게임 시작 시에만 활성화.
     * 폭발 시 '비네트 펄스' 효과를 적용하여 박진감 넘치는 연출 추가.
   - 게스트 편의성 개선:
     * 게스트 접속 시 "방장이 설정 중" 안내 화면 추가.
     * 게임 시작 시 게스트에게도 폭탄과 주제가 즉시 동기화되도록 수정.
   - 빠른 전환: 대기실 복귀 시 불필요한 확인 팝업을 제거하여 반응성 향상.

2. 빙고 (Bingo Mode) 설정 확장
   - 이벤트 타일 토글 기능: 클래식한 빙고를 원하는 유저를 위해 아이템/미션 타일 사용 여부를 방장이 결정할 수 있도록 옵션 추가.

3. 통합 설정 모달(Settings Modal) 고도화
   - 각 게임별(폭탄, 빙고, 라이어) 특성에 맞춘 설정 UI 재설계.
   - 하트 개수, 서바이벌 모드, 타이머 범위, 이벤트 사용 여부 등을 직관적으로 설정 가능하도록 개선.

4. 주요 버그 수정
   - 폭탄 돌리기 중 입력창이 응답하지 않거나 주제가 표시되지 않던 ID 매칭 오류 해결.
   - 결과 화면에서 하트 남은 개수와 생존 상태가 올바르게 표시되도록 수정.
   - 대기실 복귀 시 이전 게임의 상태값(턴 정보 등)이 남지 않도록 초기화 로직 강화.
