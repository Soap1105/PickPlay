■ 현재 이벤트 4종 + 문제점

  eventType 0: 🌀 차원 뒤틀림
    현재: 모든 플레이어 빙고판 위치만 셔플
    문제: calledNumbers는 그대로라 빙고 줄 수에 전혀 영향 없음 (사실상 무효 이벤트)
    수정안: 셔플 후 room.calledNumbers에서 랜덤 2~3개 추가 삭제하고 재broadcast

  eventType 1: 🎲 운명의 단어
    현재: 전체 풀에서 랜덤 단어 1개 추가 호명 (내 판에 없는 단어일 수도 있음)
    수정안: → "더블 픽"으로 교체
      - 이번 턴에 단어를 2개 선택할 수 있게 변경
      - 서버에서 room.doublePickActive = true 플래그 세팅
      - 클라이언트(bingo.js)에서 해당 플래그 시 첫 번째 선택 후 두 번째 선택 받기
      - 두 번째 선택 완료 후 passTurn()

  eventType 2: 🕳️ 블랙홀
    현재: allPlayerIds에서 랜덤 대상 선택 (나 자신이 될 수도 있음)
    수정안: 플레이어가 직접 타깃 선택
      - 서버: 이벤트 발동 시 클라이언트에 'select skip target' emit (대상 후보 목록 전달)
      - 클라이언트: 플레이어 목록 팝업 표시, 선택 후 서버에 'skip target selected' emit
      - 서버: 수신 후 해당 플레이어 skipCount += 1 처리

  eventType 3: 👻 유령의 장난
    현재: calledNumbers에서 랜덤 3개 삭제 (내 빙고 줄도 날아갈 수 있음)
    수정안1: 삭제된 단어들을 1~2턴간 선택 불가 상태로 잠금
      - room.lockedWords = { "단어A": 2, "단어B": 1 } 형태로 관리
      - passTurn() 호출 시마다 lockedWords 값 -1, 0이 되면 제거
      - theme word selected 핸들러에서 lockedWords 확인 후 차단
      - 클라이언트: 잠긴 단어 시각적으로 표시 (흐리게 or 자물쇠 표시)
    수정안2(선택): 삭제 대상을 나를 제외한 플레이어 단어로 한정

■ 구현 순서 추천
  1. 차원 뒤틀림 calledNumbers 삭제 추가 (가장 단순)
  2. 유령의 장난 lockedWords 잠금 (서버+클라이언트 연동 필요)
  3. 더블 픽 이벤트 교체 (클라이언트 인터랙션 추가)
  4. 블랙홀 타깃 선택 (클라이언트 팝업 필요, 가장 복잡)
