PickPlay 피드백 (부족한 점 / 보완할 점)
작성일: 2026-05-20
===========================================


[ 라이어 게임 ]

1. 게임이 기계적임
   - 설명 제출 → 투표 → 결과의 단순한 2단계 구조
   - 플레이어가 능동적으로 개입할 수 있는 순간이 설명 제출, 투표 클릭 딱 두 번뿐
   - 소셜 게임치고 상호작용이 너무 적음

2. 자유 토론 단계 없음
   - 실제 라이어 게임의 핵심은 "왜 저 사람이 라이어 같냐" 하는 심리전과 토론
   - 현재는 설명 끝나자마자 바로 투표로 넘어감
   - 채팅은 있지만 게임 흐름과 분리되어 있어 대체가 안 됨
   - → 설명 페이즈 후 자유 토론 시간 (30초~60초) 추가 고려

3. 힌트 목록 순서 문제
   - 순서가 뒤인 플레이어(특히 라이어)는 앞 사람들 설명을 다 보고 맞춰가며 작성 가능
   - 순서가 뒤일수록 라이어가 유리한 구조

4. 플레이어 수 밸런스 조정 없음
   - 3명일 때 라이어 1명 vs 시민 2명 → 투표 시 1명만 잘못 찍어도 어그러짐
   - 8명이면 라이어가 상당히 유리해짐
   - 인원 수에 따른 밸런스 조정 메카닉 없음

5. 역할 공개 연출 약함
   - "라이어" 텍스트가 그냥 뜨는 구조
   - 게임에서 가장 긴장되는 순간인데 드라마가 없음
   - 딜레이 + 카드 뒤집는 연출 등 고려

6. 투표 실시간 공개
   - 누가 투표 완료했는지 실시간으로 배지가 보임
   - 심리전 관점에서는 전원 제출 후 일괄 공개가 더 자연스러움

7. 결과창 두 개 겹침 (6-4)
   - 라운드 결과창과 최종 결과창이 따로 뜨면서 가려지는 문제
   - 통합 또는 순서 정리 필요

8. 텍스트 기반으로 라이어가 유리
   - 실제 게임에서 핵심 단서인 말투, 머뭇거림, 표정이 텍스트로 제거됨
   - 결과적으로 라이어가 숨기 더 쉬운 환경

[ 빙고 게임 ]

1. 이벤트 시스템 존재감 약함
   - 실제 플레이 시 이벤트를 거의 안 씀
   - 이벤트를 언제 쓰면 유리한지 명확하지 않음
   - 이벤트 효과가 판세를 확 뒤집는 느낌이 없음
   - 이벤트 종류, 효과, 발동 타이밍 전반적으로 재검토 필요

2. 내 차례 시각 피드백 약함
   - "👉 당신의 차례입니다!" 텍스트는 있으나 빙고판 자체 강조 없음
   - 테두리 발광, 배경 변화 등 시각적 강조 고려

3. 게임 재시작 시 이전 상태 잔류 버그 (6-2)
   - 게임 끝나고 다시 시작하면 이전 턴 메시지 등이 남아있는 경우 있음


---

[ 공통 / UI·UX ]

1. 우측 사이드바 상시 고정
   - 빙고처럼 판이 메인인 게임에서 채팅+유저 목록이 공간을 상시 차지
   - 폭탄처럼 게임 중 사이드바를 숨기는 처리 고려

2. 게임 전환 시 즉각 전환
   - 대기실 → 게임 전환이 즉시 바뀌는 구조
   - 짧은 페이드인 정도만 있어도 전환이 자연스러워짐

3. 모바일 대응
   - UUID 링크 공유 방식이라 모바일 접속 가능성 존재
   - 빙고 25칸 입력, 원형 경기장 레이아웃이 모바일에서 깨질 수 있음
   - 발표 시 누가 폰으로 접속할 경우 리스크 있음

4. "지금 내가 뭘 해야 하는지" 시각 피드백 전반적으로 약함
   - 게임 내 행동 유도(CTA)가 텍스트 위주
   - 색상, 테두리, 애니메이션 등 시각적 강조 보완 필요


---

[ 치명적 버그 ]

1. 결과 확인 중 유저가 있을 때 방장이 게임 시작 (6-3)
   - 확인을 누르고 나온 유저는 게임에 참여 불가
   - 방장도 게임 진행에 심각한 문제 발생
   - 최우선 처리 필요


---

[ 방향성 ]

1. 각 게임에서 플레이어가 능동적으로 개입하는 순간이 부족함
   - 빙고: 단어 선택 외 행동이 없음 (이벤트는 약함)
   - 라이어: 설명 제출 + 투표가 전부
   - 폭탄: 상대적으로 가장 능동적

2. 라이어 게임은 중장기적으로 구조 재검토 필요
   - 자유 토론 추가가 가장 임팩트 있는 개선
   - 발표 이후 우선순위로 고려
