### Task 1. 빙고 순위 산정 안내 모순 해결 및 백엔드 4순위 정렬 기준(방 입장 순) 명시화
- **대상 파일**:
  - 프론트엔드: `public/js/bingo.js`
  - 백엔드: `sockets/bingoHelpers.js`
- **배경 및 문제점**:
  - 결과창 우측 상단 순위 산정 기준 `(?)` 팝오버에 `'줄 수 동점 시: 이벤트 아이템 적게 사용 / 턴 입력 순'`으로 안내되고 있었음.
  - 그러나 방장이 대기실에서 턴 순서 옵션을 '랜덤(무작위)' 등으로 바꿀 수 있어 '턴 입력 순'이라는 표현은 시스템 설계와 맞지 않는 명백한 모순이었음.
  - 또한 기존 백엔드 정렬식은 아이템 횟수(`eventUsed`)까지만 비교하고 동점 시 JS 기본 배열 순서에 암묵적으로 의존하고 있었음.
- **작업 내용**:
  - **클라이언트 안내 문구 정정 (`public/js/bingo.js`)**:
    - `'줄 수 동점 시: 이벤트 아이템 적게 사용 / 턴 입력 순'` ➡️ `'줄 수 동점 시: 이벤트 아이템 적게 사용 순 (동일 시 입장 순)'`으로 수정하여 유저 혼란 방지.
  - **백엔드 정렬식 4순위 명시적 구현 (`sockets/bingoHelpers.js`)**:
    - 완성 줄 수와 아이템 사용 횟수까지 완전히 동일할 경우, 방 생성 시 기록된 방 입장 순서(`room.joinOrder.indexOf(id)`)를 4차 기준으로 명시적 비교하도록 보강.
- **검증 결과**:
  - `node -c` 구문 검사 전 파일 에러 0건 통과.
  - 클라이언트 안내 문구와 백엔드 순위 정렬 로직이 오차 없이 100% 일치하도록 정합성 확보 완료.
- **상태**: 완료 (2026-10-07)

### Task 2. 인게임 3종(빙고, 라이어, 폭탄) 공식 마스코트 SVG 연동 및 레거시 이모지 제거
- **대상 파일**:
  - `public/js/bingo.js`: 우측 플레이어 카드 아바타 마스코트 SVG 연동
  - `public/js/liar.js`: 투표 칩, 사이드바 카드, 인게임 플레이어 슬롯 마스코트 SVG 연동
  - `public/js/bomb.js`: 중앙 아레나 서바이벌 플레이어 원형 노드 마스코트 SVG 연동
  - `public/css/common.css`, `public/css/bomb.css`, `public/css/liar.css`: 인게임 아바타 원형 내 SVG 크기 및 정렬 최적화
- **배경 및 문제점**:
  - 대기실에서는 8색 고유 색상이 반영된 공식 마스코트(Pick) SVG가 적용되어 있었으나, 인게임 3종에는 아직 연동되지 않아 구형 동물 이모지(🐱, 😀)가 뜨거나(라이어/폭탄), `user.avatar` 미제공으로 인해 아바타 칸이 공백으로 유실되는(빙고) 시각적 불일치가 존재했음.
- **작업 내용**:
  - **빙고 우측 플레이어 카드 (`bingo.js`)**: `user.avatar` 대신 `window.buildMascotSvg(user.color)`를 주입하여 각 참가자의 고유 색상 마스코트가 상시 노출되도록 복원.
  - **라이어 게임 (`liar.js`)**: 투표 칩, 대기 카드, 인게임 슬롯에서 동물 이모지 fallback을 제거하고 마스코트 SVG로 전면 전환.
  - **폭탄 돌리기 (`bomb.js`)**: 아레나 서바이벌 플레이어 원형 노드에 각자의 고유 색상 마스코트 SVG 주입.
  - **CSS 최적화**: `.avatar`, `.liar-slot-avatar`, `.arena-avatar` 내 SVG가 찌그러짐 없이 1:1 종횡비로 중앙에 안정적으로 안착하도록 크기 규칙 통일.
- **검증 결과**:
  - `node -c` 구문 검사 전 파일 PASS.
  - 대기실부터 빙고, 라이어, 폭탄 인게임 전반에 걸쳐 통일된 마스코트 정체성 확보 완료.

### Task 4. 라이어 게임(일반/워드 모드) 라운드 종료 승점 동기화 누락 및 최후 변론 타임아웃 점수 미지급 버그 해결
- **대상 파일**:
  - 백엔드: `sockets/liarSocket.js`
  - 프론트엔드: `public/js/liar.js`
- **배경 및 문제점**:
  - 라이어 게임(워드 모드 및 일반 모드)에서 라이어가 방어에 성공하거나, 시민들이 라이어를 검거하여 승리해도 다음 라운드 진입 시 플레이어 슬롯 상단 승리 도트(점수)가 전혀 오르지 않고 0개로 유지되는 치명적인 버그가 존재했음.
  - 또한 라이어가 검거된 뒤 최후 변론 30초 시간 초과로 시민 승리 판정이 났을 때, 서버 내부에서 시민 플레이어들에게 점수를 지급하는 로직이 아예 누락되어 있었음.
  - 라운드 종료(`ROUND OVER`) 안내 패널에도 각 유저의 현재 누적 승수를 보여주는 현황판이 없어 유저가 점수 획득 여부를 확인할 수 없었음.
- **작업 내용**:
  - **최후 변론 타임아웃 점수 지급 보강 (`sockets/liarSocket.js`)**:
    - 라이어가 30초 내에 변론을 제출하지 못해 시민 승리로 종료될 때, 라이어를 올바르게 지목한 시민들의 `scores[voter]`를 +1 증가 처리.
  - **라운드 종료 및 시작 시 실시간 점수 브로드캐스트 (`sockets/liarSocket.js`)**:
    - `handleRoundEnd` 시작 시점에 `io.to(roomId).emit('update scores', room.liarGame.scores, target)`를 필수로 호출하여 전원에게 최신 점수를 즉시 브로드캐스트.
    - `startRound` 시점에도 방어 차원에서 `update scores` 재동기화 보장.
  - **클라이언트 점수 동기화 및 라운드 스코어보드 구현 (`public/js/liar.js`)**:
    - `round over` 수신 시 `result.stats`를 기반으로 `window.gameScores` 전역 상태를 즉시 최신화하고, 백그라운드 슬롯 도트 리렌더링.
    - `ROUND OVER` 안내 패널 내에 각 참가자의 고유 마스코트 SVG, 닉네임, 현재 누적 승수(`현재 N / 목표 M승`)를 일목요연하게 확인할 수 있는 미니 스코어보드 바 신설.
- **검증 결과**:
  - `node -c sockets/liarSocket.js`, `node -c public/js/liar.js` 구문 검사 100% 통과.
  - 라이어 승리/검거 승리/타임아웃 승리 전 시나리오에서 누적 승수 및 인게임 슬롯 도트 정상 갱신 확인.
- **상태**: 완료 (2026-10-07)
