1. 금주 아이디어 및 기획

1. 게임 전반 디자인 개편 및 고유 마스코트 도입
- 생성형 AI 기술을 활용하여 PickPlay만의 고유 마스코트 캐릭터를 제작하고, 이를 중심으로 UI 전반의 이모지 의존도를 대폭 낮추며 대기실에 마스코트 캐릭터를 띄우기.

2. 빙고 게임 관련 개선 사항
- 기존 빙고 게임에 탑재된 단어DB가 오래되어 최신 트렌드를 반영하지 못하던 문제 개선.

3. 모든 게임 공통적 적용 사항
- 기존의 단순 텍스트 기반 결과창을 제거한 뒤 본인의 플레이어 카드와 함께 자신이 몇 등인지 확인이 가능하게 결과창 디자인을 변경.

4. 대기실 관련 수정 사항
- 대기실 하단에 배치되어있던 '이모지 폭죽' 기능을 제거.
- 플레이어의 구분을 위해 플레이어 카드 색 변경 기능 추가.

5. 기타 개선 사항
- 게임 도중 브라우저 새로고침이나 일시적인 네트워크 끊김으로 인해 방에서 튕겼을 때, 진행 중이던 세션을 잃지 않고 기존 방으로 안전하게 재입장할 수 있는 복구 방안 기획.


2. 금주 개선 및 업데이트 내용

1. PickPlay 마스코트 도입

• 이름 : 미정
• 역할 : 게임을 플레이하는 유저들을 식별하기 위하여 만든 캐릭터.
• 의도 : 유저들이 빈 시간동안 자신의 캐릭터를 커스텀하며 시간을 보내는 용도 + 자신의 귀여운 캐릭터를 커스텀하는 만족감을 주기 위함 + 게임의 마스코트가 있을 때, 이 캐릭터를 보고 게임의 인지도 및 재방문률 증가를 의도함입니다.

(사진 1) - PickPlay의 마스코트

2. 빙고 게임 관련 개선 사항

• DB 데이터 최신화
- 빙고 DB의 기간값을 새로 부여한 뒤, 일정 기간(3주)이 지나면 DB캐싱이 아닌, 새롭게 데이터를 가져오도록 변경했습니다.
- 기존 빙고 게임에 탑재된 단어DB가 오래되어 최신 트렌드를 반영하지 못하던 문제를 개발 도중 겪게되었고, 이를 보완할 방법을 생각하여 이러한 방법을 적용하게 되었습니다.
- 예외처리로 AI가 오류가 발생하여 빙고 데이터를 검색할 수 없게된 경우에는 기존 DB에 있던 데이터를 캐싱하여 사용할 수 있게 설계했습니다.

3. 모든 게임 공통적 적용 사항

3-1. 게임 결과창 모달 전면 리디자인 및 인게임 연동
- 기존에 존재하던 구식 디자인의 결과창을 걷어내고 새롭게 디자인하여 게임 결과를 알아보기 쉽게 변경했습니다.
- 개발 목적 : 단순 텍스트 위주의 결과 발표를 개선하여 시각적 성취감을 제공하고 게임의 흐름을 쉽게 알아볼 수 있게 하기 위함입니다.

(사진 2) – 게임 결과 화면

3-2. 순위 산정 기준 안내 팝오버 및 탭 분기 도입
- 결과창 우측 상단에 순위 산정 기준 물음표(?) 버튼을 추가하여, 클릭 시 동점자 처리 기준과 승리 조건을 단계별 리스트로 한눈에 확인할 수 있도록 하였습니다.
- 백엔드 서버의 순위 산정 알고리즘을 1위 우승자 우선, 세부 지표 내림차순 등의 다중 조건 정렬로 완벽히 일치시켰습니다.
- 개발 목적 : "내가 왜 2위인지", "지난 라운드에 무슨 일이 있었는지" 궁금해하던 유저들의 정보 갈증을 해소하고 게임의 투명성과 몰입감을 높이기 위함입니다.

(사진 3) – 게임의 승리조건을 보여주는 팝업 클릭

4. 대기실 관련 개선 사항 

• 불필요한 폭죽 기능 전면 삭제를 통한 화면 및 성능 최적화
- 대기실 하단에 고정되어 공간을 낭비하고 화면에 이모지가 떠다녀 주요 정보를 가리던 '이모지 폭죽' 버튼 바와 토글 스위치를 전면 삭제하였습니다.
- 결과창 재개발로 인하여, 게임 종료 시 나오던 축하하는 폭죽 효과 역시 제거했습니다.
- 개발 목적 : 불필요한 연출로 인한 시각적 피로도와 렉(프레임 드랍)을 제거하고, 게임 진행과 결과 확인이라는 본질에 온전히 집중할 수 있는 깔끔한 환경을 조성하기 위함입니다.

5. 기타 개선 사항

• 일시적 연결 단절 대비 세션 유지 및 재입장 예외 처리
- 게임 진행 도중 브라우저 새로고침이나 일시적인 네트워크 불안정으로 인해 접속이 끊겼을 때, 즉시 방에서 영구 퇴장되지 않고 일정 시간 동안 유저의 룸 ID와 닉네임 세션 정보를 보존하도록 개선하였습니다.
- 개발 목적 : 단순 네트워크 오류나 실수로 인한 새로고침으로 인해 파티가 해체되거나 게임에서 강제 이탈되는 불편을 방지하기 위함입니다.
