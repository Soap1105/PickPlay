1. 금주 아이디어 및 기획

1. 게임 플레이 및 편의성 개선 사항
- 폭탄 돌리기 전략 모드에서 원하는 대상을 직관적으로 지목할 수 있는 번호 표시 및 타겟 락온 기능 기획
- 라이어 게임 진행 중 혼란을 줄 수 있는 투표 및 대기 안내 문구 명확화 기획
- 방 입장 로딩 화면에 부드러운 애니메이션과 단계별 안내 문구를 적용하여 시각적 완성도를 높이는 기획
- 대기실에서 로딩 화면의 연출을 손쉽게 확인할 수 있는 테스트 토글 버튼 기획
- 폭탄 돌리기 게임 중 목숨(하트)이 깎이는 연출을 안정적으로 관리하기 위한 내부 로직 개선 기획

• 이번 주는 인게임 플레이 편의성, 로딩 화면 비주얼 연출, 그리고 게임 내 안내 문구 개선을 중점으로 진행했습니다.


2. 금주 개선 및 업데이트 내용

1-1. 폭탄 돌리기 게임 개선 사항

• 플레이어 지목 번호 배지 및 타겟 락온 기능 추가
- 전략 모드 진행 시 다른 플레이어를 쉽게 지목할 수 있도록 각 참가자 상단에 1, 2, 3... 형태의 고유 번호 배지를 추가하였습니다.
- 서버의 참가자 순번과 실시간으로 동기화하여 모든 플레이어의 화면에서 동일한 번호가 보이도록 처리하였습니다.
- 내 턴에 다른 플레이어를 선택했을 때 붉은색 타겟 락온 테두리가 표시되어 지목 대상을 한눈에 알아볼 수 있도록 개선하였습니다.
- 개발 목적 : 빠르게 단어를 이어가야 하는 게임 특성상, 지목 대상을 헷갈리지 않고 직관적으로 선택할 수 있도록 돕기 위함입니다.

(사진 1) – 플레이어 상단에 지목 번호 배지가 표시된 폭탄 아레나 화면.
(사진 2) – 지목 대상을 클릭했을 때 붉은색 락온 테두리가 활성화된 화면.

• 목숨(하트) 표시 렌더링 최적화
- 아레나 화면과 스코어보드에서 제각각 동작하던 하트 표시 방식을 하나의 공통 시스템으로 일원화하였습니다.
- 폭탄이 터져 목숨이 줄어들 때 실시간으로 하트 색상(빨간 하트 ➡️ 검은 하트)이 자연스럽게 변경되도록 다듬었습니다.
- 개발 목적 : 화면 간 목숨 표시 불일치를 방지하고 시각적 피드백을 정확하게 전달하기 위함입니다.

(사진 3) – 게임 진행 중 하트가 정상적으로 차감되는 아레나 화면.


1-2. 라이어 게임 문구 개선 사항

• 직관적인 투표 및 대기 안내 문구 정정
- 투표 단계에서 본인을 지목했을 때 나오던 어색한 문구("자신의 힌트에는 투표할 수 없습니다!")를 "본인에게는 투표할 수 없습니다!"로 명확하게 수정하였습니다.
- 라운드가 끝난 뒤 게스트 화면에 노출되던 불필요한 문구를 정리하고, "방장이 다음 라운드를 준비하고 있습니다."로 통일하여 다음 진행 상황을 쉽게 알 수 있도록 개선하였습니다.
- 개발 목적 : 사용자에게 게임 규칙과 현재 진행 상황을 왜곡 없이 명확하게 안내하기 위함입니다.


1-3. 방 입장 로딩 화면 및 편의 기능 개선

• 로딩 화면 비주얼 연출 및 단계별 안내 문구 개선
- 로고가 부드럽게 떠오르며 숨을 쉬듯 은은하게 빛나는 호흡 애니메이션과 웨이브 도트 효과를 적용하여 고급스러운 느낌을 주었습니다.
- 단순 "연결 중..." 고정 문구 대신 접속 진행 상황에 맞춰 "서버에 연결하는 중..." ➡️ "게임 환경을 준비하는 중..." ➡️ "입장 준비 완료!"로 문구가 순차적으로 바뀌도록 개선하였습니다.
- 방 진입 완료 시 로딩 화면이 부드럽게 확대되며 자연스럽게 대기실로 전환되도록 처리하였습니다.
- 개발 목적 : 방에 들어가는 짧은 시간 동안에도 지루함을 덜고 연결 과정을 시각적으로 친절하게 전달하기 위함입니다.

(사진 4) – 로고 애니메이션과 새로운 단계별 문구가 적용된 로딩 화면.

• 로딩 화면 미리보기 토글 버튼 추가
- 채팅창 상단의 다크/라이트 모드 버튼 옆에 스피너 모양의 로딩 미리보기 버튼을 추가하였습니다.
- 버튼 클릭 시 2.3초간 로딩 연출을 확인할 수 있으며, 화면 아무 곳이나 누르면 즉시 닫히도록 구현하였습니다.
- 개발 목적 : 방에 재접속하지 않고도 언제든 로딩 화면의 연출과 테마별 반응을 간편하게 테스트할 수 있도록 지원하기 위함입니다.

(사진 5) – 채팅 헤더에 배치된 로딩 미리보기 버튼 및 다크/라이트 모드 버튼.


3. 다음 주 개발 및 고려 사항

1. 게임별 비주얼 테마 및 이벤트 카드 리디자인
- 게임 선택 시 대기실 배경 색상을 해당 게임의 고유 테마(빙고: 블루, 라이어: 레드, 폭탄: 옐로우/오렌지)로 전환하고, 다크/라이트 모드와 어우러지도록 CSS 변수 및 색상 시스템 고도화하기.
- 빙고 게임의 특수 이벤트 팝업을 투박한 시스템 기본 이모지에서 세련된 전용 일러스트 카드 및 글래스모피즘 프레임으로 전면 리디자인하기.

2. 게임 시작 및 결과 발표 몰입감 연출 도입
- 방장이 게임을 시작했을 때 참가자 모두가 준비할 수 있도록 화면 중앙에 대형 3초 카운트다운(3 ➡️ 2 ➡️ 1 ➡️ START!) 연출 추가하기.
- 최종 게임 승리자 발표 시 화면 전체에 화려한 축하 파티클(Confetti) 폭죽 효과 및 우승자 하이라이트 연출 도입하기.

3. 신규 4번째 미니게임 '블러핑 파티(가칭 바보 게임)' 기획 및 룰 설계
- 폭탄 돌리기와는 별개로, 상대방의 거짓말을 간파하고 역으로 낚아채는 심리전/블러핑 기반 신규 독립 미니게임의 시스템 룰 및 UI 구조 설계 검토하기.
