1. 금주 아이디어 및 기획

1. 마스코트 관련 개선 사항
- 대기실에만 보이던 캐릭터를 인게임 전체에 적용하기.
- 마스코트 이름을 게임의 이름을 따 '픽(Pick)'으로 확정.
- 대기실·게임 대기방 UI/UX 통합 및 마스코트 커스텀 접근성 강화.

2. 빙고 게임 관련 개선 사항
- 여러 명 플레이 시, 사이드바에 참여자 목록이 작게 보이던 문제가 발생하여 화면 배치를 재수립 및 기획.
- AI 테마 단어의 데이터 보관 주기(30일) 및 자동 최신화 전략 정립.

3. 기타 개선 사항
- 새로고침이나 일시적 연결 종료 시 게임이 멈춰 방에 갇히는 버그 수정.


2. 금주 개선 및 업데이트 내용

2-1. 마스코트 관련 개선 사항

• 인게임 전체 캐릭터 적용
- 기존에 인게임 화면에서 표시되던 동물 이모지를 제거하고, 마스코트 캐릭터 '픽(Pick)'을 게임 화면 전체에 적용하였습니다.
- 개발 목적: 참가자들이 서로를 직관적으로 구분하고 시각적 통일감을 제공하기 위함과 더불어, 기존의 동물 이모지는 게임에 어울리지 않는다고 생각하여 이를 수정했습니다.

• 최대 인원에 맞는 컬러 연동
- 방 입장 시 플레이어에게 부여되는 최대 8가지 색상을 골라 마스코트 캐릭터에 반영되도록 연동하였습니다.
- 개발 목적: 색을 통해 서로를 명확히 구분하며, 내 캐릭터라는 소속감을 부여하기 위해 제작했습니다.

2-2. 빙고 게임 관련 개선 사항

• 빙고 게임 화면 3단 분할 레이아웃 개편
- 빙고 게임 화면이 좁다고 판단하여 전체적인 UI를 개선했습니다.
- 좌측(참여자 목록), 중앙(5×5 빙고판), 우측(채팅)으로 화면 영역을 3단 분할 배치하여 참여자 목록 UI를 확대하고 캐릭터 아바타 크기를 크게 볼 수 있도록 수정했습니다.
- 개발 목적: 마스코트를 도입하면서 참여자 목록칸이 작다는 문제점이 생겼고, 이를 해결하기 위해 빙고 게임의 UI를 대폭 수정하여 자신의 마스코트 캐릭터가 더 잘 보일 수 있게 수정했습니다.

• 빙고 테마 데이터 30일 주기 보관 및 자동 갱신 체계 구축
- DB에 보관된 지 30일이 지난 데이터는 최신 유행어와 트렌드를 반영하기 위해 DB에 존재하더라도, AI 검색을 다시 시도하여 새로운 단어 목록으로 갱신되도록 개선하였습니다.
- Gemini API 네트워크 오류가 발생하더라도 게임이 멈추지 않고 기존에 있는 DB를 캐싱하여 끊김 없이 플레이할 수 있도록 안전장치를 마련했습니다.
- 개발 목적: AI가 만든 데이터들이 오래되면 유행에 뒤처지고 원하는 단어를 얻을 수 없다고 판단하여 데이터의 유통기한을 30일로 설정하고 최신 데이터를 사용할 수 있도록 조치하기 위함입니다.

2-3. 기타 개선 사항

• 게임 중 새로고침(F5) 시 즉시 복구 및 결과창 잠금 결함 해소
- 플레이어가 게임 도중 실수로 브라우저를 새로고침하더라도 기존 빙고판 상황과 잔여 턴 시간을 원래대로 즉각 복구하도록 구현했습니다.
- 결과 화면에서 새로고침 시 '결과 확인 중' 상태에 영구히 갇혀 다음 게임을 진행할 수 없던 결함을 해소했습니다.
- 개발 목적: 게임 도중 실수로 새로고침을 눌러 억울하게 방에서 튕기거나 패배 처리되는 것을 방지하고, 결과 화면에서 세션이 멈춰 다음 게임으로 넘어가지 못하던 문제를 해결하여 원활한 플레이 흐름을 보장하기 위함입니다.

• 상대방 이탈 시 잔류 플레이어 기권승(몰수승) 처리
- 2인 이상 게임 중 상대방이 창을 완전히 닫거나 연결을 종료하여 1명만 남았을 경우, 불필요한 대기 없이 즉시 기권승(몰수승) 안내 팝업을 띄우고 승리 효과음과 함께 대기실로 안전하게 복귀하도록 처리했습니다.
- 개발 목적: 1:1 상황 등에서 상대방의 비매너 탈주나 네트워크 끊김으로 인해 남은 유저가 방에 갇혀 무한정 대기하거나 게임이 비정상 종료되는 현상을 방지하기 위함입니다.
