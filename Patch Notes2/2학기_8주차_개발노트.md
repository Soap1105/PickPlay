### Task 1. 빙고 인게임 새로고침(F5) 시 BGM 증발 결함 해결 및 Autoplay 영구 언락 파이프라인 구축
- **대상 파일**:
  - 프론트엔드: `public/js/soundManager.js`, `public/js/bingo.js`
- **배경 및 문제점**:
  1. 빙고 게임 도중 브라우저를 새로고침(F5)하면 보드판과 턴 상태는 정상 복구되지만, 배경음(BGM)이 다시 켜지지 않고 무음 상태로 증발하는 결함 발생.
  2. 원인 분석 결과, 새로고침 직후 페이지가 다시 로드되면서 유저의 클릭 인터랙션이 발생하기 전에 소켓 복구 패킷(`start theme game`)에 의해 `playBgm('bingo')`가 먼저 호출되어 브라우저 오디오 보안 정책(`NotAllowedError: play() failed without user interaction`)에 의해 차단됨.
  3. 기존 1회성 언락 리스너가 BGM 객체 생성 시점과 어긋나 소멸되었고, 재생 실패 시 재시도 큐잉(`pendingBgm`)이 없어 유저가 화면을 클릭해도 BGM이 깨어나지 못함.
- **작업 내용**:
  - **`pendingBgm` 대기 큐 및 상태 머신 신설 (`soundManager.js`)**:
    - `playBgm(name)` 호출 시 브라우저 차단(`NotAllowedError`)이 발생하더라도 BGM을 폐기하지 않고 `this.pendingBgm = name`으로 등록.
  - **지능형 지속 언락 무장 시스템(`_armAutoplayUnlock`, `_disarmAutoplayUnlock`) 탑재**:
    - 브라우저 창 전체(`window`)에 캡처링 모드(`capture: true`)로 `click`, `keydown`, `pointerdown`, `touchstart` 이벤트를 등록.
    - 새로고침 후 유저가 보드판 단어를 누르거나 화면 어디든 1회 클릭/터치/키 입력하는 즉시 대기 중이던 `pendingBgm`을 감지하여 원래 설정된 볼륨으로 BGM을 즉각 자동 재생하도록 완성.
    - 음소거 해제 시 및 동일 BGM 일시정지 상태 복원 시에도 인터랙션 언락 연동.
    - 게임 종료(`stopBgm`) 시에는 `pendingBgm`과 이벤트 리스너를 즉시 해제(`_disarmAutoplayUnlock`)하여 불필요한 사운드 오작동 원천 차단.
- **검증 결과**:
  - `node -c public/js/soundManager.js public/js/bingo.js` 구문 검사 오류 0건 통과.
  - 인게임 빙고 도중 F5 새로고침 후 화면 클릭 시 원래 볼륨으로 BGM 즉각 재생 복원 확인.
  - 음소거 설정(`localStorage`) 상태에서 새로고침 시 무음 유지 확인.
  - 게임 종료 및 대기실 복귀 시 BGM 정상 정지 확인.
- **상태**: 완료 (2026-10-27)

### Task 2. 라이어 게임 새로고침(F5) 세션 복구 및 중도 탈주·이탈 4중 예외 방어 구축
- **대상 파일**:
  - 백엔드: `sockets/liarSocket.js`, `sockets/commonSocket.js`
  - 프론트엔드: `public/js/liar.js`
- **배경 및 문제점**:
  1. 기존에는 `commonSocket.js`에 빙고 복구만 존재하고 라이어 복구 분기가 전무하여, 라이어 플레이 도중 실수로 브라우저를 새로고침(F5)하면 대기실로 튕기거나 화면이 멈추는 치명적 세션 유실 결함 존재.
  2. 라이어가 게임 도중 브라우저를 닫거나 인터넷 연결이 끊겨 탈주했을 때 판정 로직이 없어 시민들이 무한정 대기하거나 게임이 먹통이 됨.
  3. 발언자가 발언 도중 나갔을 때 턴이 다음 사람에게 넘어가지 않거나, 투표 도중 유저가 나갔을 때 잔여 인원수 대비 투표 완료율이 맞지 않아 다음 단계로 넘어가지 못하는 취약점 존재.
- **작업 내용**:
  - **라이어 0초 세션 복구 파이프라인 (`restore liar state`) 구축**:
    - `buildLiarRecoveryData` 헬퍼 함수를 신설하여 재접속한 클라이언트에게 본인의 역할(라이어/시민), 제시어 보안 마스킹, 현재 페이즈(`submission`, `playing`, `final_guess`, `ROUND_OVER`), 누적 힌트 말풍선 목록, 현재 턴 정보, 잔여 타이머, 점수판을 원자적으로 번들링 전송.
    - `liar.js`에서 복구 패킷 수신 시 카운트다운 연출을 건너뛰고 3D 역할 카드(앞면 상태), 기존 발언 말풍선, 현재 발언 입력창 또는 투표 슬롯을 0초 즉시 복원.
  - **중도 탈주·이탈 4중 자동 방어 시스템 (`handleLiarPlayerDisconnect`) 구축**:
    - **라이어 탈주 시**: `leavingSocketId === liarId` 감지 즉시 타이머를 정리하고 `"라이어가 연결을 종료하여 시민들의 승리로 종료되었습니다."` 시스템 공지와 함께 생존 시민 전원 승점 부여 및 즉시 승리 라운드 마감.
    - **발언자 탈주 시**: 발언 순서(`turnOrder`)에서 즉시 제명하고, 현재 발언자가 나간 경우 다음 순서 플레이어에게 발언 턴을 자동 승계(`sendNextTurn`). 전원 발언 완료 시 자동으로 투표 단계 전환.
    - **투표자 탈주 시**: 탈주자의 투표 표를 정리하고 남은 생존 플레이어 기준으로 투표 완료 여부를 재검사하여, 전원 완료 시 즉시 개표로 진행.
    - **최소 인원(3인) 미만 도달 시**: 무한 대기 없이 `"인원 부족(최소 3명 필요)으로 게임이 종료되었습니다."` 알림과 함께 방 전체가 대기실로 안전하게 복귀하도록 예외 방어.
- **검증 결과**:
  - `node -c sockets/liarSocket.js sockets/commonSocket.js public/js/liar.js` 구문 검사 전 파일 통과 (오류 0건).
  - 발언 중 새로고침 시 제시어 카드, 기존 말풍선, 턴 입력창 정상 복원 확인.
  - 투표 중 새로고침 시 투표 록온 타겟 및 타이머 정상 복원 확인.
  - 라이어 탈주 시 즉시 시민 승리 판정 및 라운드 결과 처리 확인.
- **상태**: 완료 (2026-10-27)

### Task 3. 라이어 게임 마스코트 퀵 감정표현(이모지 4종) 핑 시스템 구축 및 레이아웃 안정화
- **대상 파일**:
  - 백엔드: `sockets/liarSocket.js`
  - 프론트엔드: `public/js/liar.js`, `public/css/liar.css`
- **배경 및 목적**:
  1. 라이어 게임은 턴제 발언의 집중도 유지를 위해 자유 텍스트 채팅창을 배제하고 있으나, 다른 플레이어의 발언이나 의심 상황에서 즉각적인 감정 표현 및 리액션을 주고받을 인터랙션 수단이 없었음.
  2. 텍스트 없이 직관적인 이모지(의심, 눈치, 당황, 동의)를 통해 조작 피로도 없이 1초 만에 위트 있는 심리전 리액션을 표출할 수 있는 퀵 핑 시스템 필요.
  3. 턴 전환 시 하단 입력창이 나타나고 사라지면서 화면 전체가 위아래로 출렁이는 레이아웃 시프트(덜컹거림)를 제거하여 안정된 시각적 경험 확보 필요.
- **작업 내용**:
  - **백엔드 소켓 이벤트 연동 (`sockets/liarSocket.js`)**:
    - 허용된 4종 이모지(`❓`, `👀`, `💦`, `👍`)에 대한 유효성 검증을 포함한 `liar reaction` 소켓 리스너 구현 및 `liar reaction broadcast` 전파.
  - **프론트엔드 퀵 팔레트 UI 및 마스코트 핑 애니메이션 연동 (`liar.js`, `liar.css`)**:
    - 인게임 하단에 글래스모피즘 캡슐형 이모지 4종 팔레트(`#liar-reaction-palette`) 동적 생성 및 0.7초 쿨다운 적용.
    - 리액션 수신 시 해당 플레이어 아바타 상단에 `@keyframes emojiPingPop` 애니메이션으로 튀어 오르는 핑(`.liar-slot-emoji-ping`) 렌더링 후 1.5초 뒤 자동 소멸.
  - **화면 덜컹거림(Layout Shift) 방지 (`liar.css`)**:
    - `#liar-input-zone`의 높이를 `min-height: 80px` 고정 플렉스 영역으로 마감하여, 턴 교체 시 보드판 위치가 흔들리지 않도록 고정.
- **상태**: 완료 (2026-10-28)

### Task 4. 라이어 게임 세션·투표 락 버그 픽스 및 인게임/결과창/화이트 모드 UI/UX 전면 고도화
- **대상 파일**:
  - 백엔드: `sockets/commonSocket.js`, `sockets/liarSocket.js`
  - 프론트엔드: `public/js/liar.js`, `public/css/liar.css`, `public/js/bingo.js`, `public/css/bingo.css`, `public/css/common.css`
- **작업 내용**:
  - **F5 재접속 소켓 ID 완벽 마이그레이션 (`sockets/commonSocket.js`)**:
    - 재접속 시 `room.liarGame` 내의 `turnOrder`, `liarId`, `scores`, `submissions`, `votes`의 모든 `oldSocketId`를 신규 `socket.id`로 마이그레이션하여 내 턴 입력 권한 및 3D 역할 카드 정상 복구.
  - **투표 상태 잠금(Lock) 및 2라운드 개표 락 리셋 (`sockets/liarSocket.js`, `public/js/liar.js`)**:
    - 새 라운드 시작 시(`startRound`) 및 투표 페이즈 진입 시(`proceedToVotingPhase`) `isTallying = false`를 명시적으로 리셋하여 **2번째 라운드 투표 시 개표가 멈추는 버그 완벽 해결**.
  - **인게임 조작성 및 라운드 전환 트랜지션 고도화 (`sockets/liarSocket.js`, `public/js/liar.js`, `public/css/liar.css`)**:
    - 1라운드(최초 게임 시작) 및 다음 라운드 시작 시 화면 중앙에 **3초 카운트다운(`3... 2... 1...`)**을 거친 후 새 라운드로 전환되도록 일원화.
    - 내 발언 제출 후에도 내 3D 역할 카드(`#liar-my-card`)가 말풍선으로 덮어씌워져 증발하지 않도록 보존하고, 내 설명은 카드 하단 캡슐 칩(`#liar-my-speech-chip`)으로 함께 표시하여 라운드 내내 언제든 카드를 뒤집어 단어를 확인할 수 있도록 수정.
    - 라이어 역할 카드의 불필요한 `(제시어 모름)` 문구를 제거하고 `?` 단독 표기로 간결화.
    - 화이트 모드 역할 카드의 과도한 원색 뱃지/보더를 다크모드와 동일한 은은한 반투명 파스텔 뱃지·보더로 조율.
    - 투표 단계 호버 시 슬롯 전체를 덮던 검은색/빨간색 `투표` 오버레이를 제거하고, 상대의 발언 말풍선을 가리지 않는 하단 플로팅 캡슐(`지목하기`) 및 인디고 보더 광원으로 개편.
  - **결과창 UI 문구 최신화 및 대기실·빙고 화이트 모드 시인성 개선**:
    - `ROUND OVER` 대신 `시민 승리` / `라이어 승리` 타이틀 적용, 승수를 빙고 스타일 골드 도트(`● ● ○`)로 시각화, 섹션 명칭(`스코어`, `플레이어 발언`, `투표 결과`, `채팅`) 정돈 및 불필요한 아이콘 제거.
    - 대기실 빈 슬롯 깨진 한글(`비어있음`) 복원 및 빙고 화이트 모드 텍스트/보드판 대비 개선.
- **상태**: 완료 (2026-10-28)

## 2. 주간 개발 결과 총평
- 빙고의 새로고침 BGM 증발 결함(Autoplay 차단)을 해결하고, 라이어 게임의 **새로고침(F5) 세션 복구**, **중도 탈주 4중 방어**, **2라운드 개표 락 버그**를 완결함.
- 라이어 게임에 마스코트 퀵 감정표현(4종)과 3초 시작 카운트다운을 도입하고, 3D 역할 카드 상시 확인, 세련된 투표 호버(`지목하기`), 골드 도트 결과창 및 화이트 모드 파스텔 톤앤매너까지 전면 리뉴얼하여 완성도를 끌어올림.
