# PickPlay 구조 요약 (1분 버전)

> 상세 버전은 `코드구조_메모.md` 참고.

---

## 1. 서버는 게임을 진행하고, 브라우저는 화면만 그린다

- 서버에 `gameRooms`라는 메모장이 하나 있다. 방마다 누가 있고 지금 어떤 상황인지 여기에 적혀 있다.
- 브라우저는 정보를 저장하지 않는다. 서버가 알려주는 대로 그리기만 한다.

## 2. 파일은 게임마다 서버용과 화면용이 한 쌍이다

| | 서버 (규칙 계산) | 화면 (보여주기) |
| :--- | :--- | :--- |
| 대기실 | `sockets/commonSocket.js` | `public/js/room.js` |
| 빙고 | `sockets/bingoSocket.js` | `public/js/bingo.js` |
| 라이어 | `sockets/liarSocket.js` | `public/js/liar.js` |
| 폭탄 | `sockets/bombSocket.js` | `public/js/bomb.js` |

## 3. 모든 동작은 똑같이 움직인다

1. 유저가 클릭하면 서버에 알린다 (`emit`)
2. 서버가 메모장(`gameRooms`)을 고친다
3. 서버가 방 전체에 알려준다
4. 모두의 화면이 바뀐다

## 4. 화면은 `game.html` 하나뿐이다

대기실, 빙고, 라이어, 폭탄 화면이 한 파일 안에 다 있고, 필요한 것만 보이게 켜고 끈다.

---

## 어디를 보나

- 화면이 이상하다 -> 화면 쪽 `public/js/xxx.js`, `public/css/common.css`
- 규칙이나 계산이 이상하다 -> 서버 쪽 `sockets/xxxSocket.js`
