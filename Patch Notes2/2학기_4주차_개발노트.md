## 1. 진행 예정 과제 (To-Do)

### Task 1. 폭탄 돌리기 게임 시작 카운트다운 타이머 동기화 보정
- **대상 파일**: `sockets/bombSocket.js`, `public/js/bomb.js`
- **배경 및 문제점**:
  - 1라운드 시작 시 클라이언트 화면에서 3초 카운트다운(3-2-1-START)이 진행되는 동안, 백엔드 서버의 폭탄 타이머가 백그라운드에서 즉시 차감되기 시작함.
  - 이로 인해 1라운드 첫 턴을 부여받은 플레이어가 약 3초가량의 입력 시간을 억울하게 손해 보며 시작하는 비동기 타이밍 문제가 발생함.
- **작업 내용**:
  - **서버 폭탄 타이머 기동 타이밍 보정 (`sockets/bombSocket.js`)**:
    - 1라운드 시작 신호(`bomb round started`) 브로드캐스트 시, 첫 턴에 한해 3초 딜레이 후 폭탄 타이머 인터벌이 작동하도록 보정하거나 카운트다운 완료 이벤트와 동기화.
    - 2라운드 이후 또는 인게임 턴 패스 시에는 카운트다운이 없으므로 기존 즉시 기동 로직 유지.
  - **클라이언트 동기화 피드백 (`public/js/bomb.js`)**:
    - 카운트다운 3초 동안 인게임 타이머 게이지 바 및 카운터가 소모되지 않고 대기 상태를 유지하도록 표시 동기화.
- **검증 결과**:
  - `node -c sockets/bombSocket.js public/js/bomb.js` 구문 검사 통과.
  - 브라우저 서브에이전트 2인(방장, 게스트) 실측 검증 완료:
    - 1라운드 시작 시 3초 카운트다운(약 3.5초) 동안 서버 타이머 선차감 없이 대기함.
    - 카운트다운이 완전히 끝나는 순간부터 첫 번째 턴 플레이어의 15초 제한 시간과 폭탄 타이머가 정시에서 줄어들기 시작함을 확인.
- **상태**: 완료 (2026-09-22)

### Task 2. 게임 선택에 따른 대기실 비주얼 테마(배경 무드) 전환 연출
- **대상 파일**: `public/js/room.js`, `public/css/common.css`
- **배경 및 기획**:
  - 현재 방장이 대기실에서 게임(빙고, 라이어, 폭탄)을 선택했을 때 좌측 카드의 active 상태만 바뀔 뿐 전체적인 공간 분위기의 변화가 부족함.
  - 각 게임의 고유 상징 컬러(빙고: 네온 블루, 라이어: 크림슨 레드, 폭탄: 앰버 오렌지)에 맞춰 대기실 전체 배경 그라데이션 및 앰비언트 글로우가 부드럽게 전환되도록 연출하여 시각적 몰입감을 극대화.
- **작업 내용**:
  - **대기실 테마 클래스 동적 전환 (`public/js/room.js`)**:
    - `game changed` 이벤트 수신 시 `body`에 게임별 테마 클래스(`lobby-theme-bingo`, `lobby-theme-liar`, `lobby-theme-bomb`)를 동적으로 부여/제거.
    - 로비 복귀(`newGameType === 'lobby'`) 시 모든 테마 클래스를 제거하여 기본 배경으로 자연스럽게 복원.
    - 인게임 진입(`showContainer` 호출 시) 시점에도 `lobby-theme-*` 클래스 클리어 보장. 인게임은 `game-active-*` 클래스로 별도 관리.
  - **배경 그라데이션 트랜지션 및 앰비언트 효과 (`public/css/common.css`)**:
    - `body`에 `transition: background 0.85s cubic-bezier(0.4, 0, 0.2, 1)` 추가로 부드러운 전환 보장.
    - 라이트 모드: 빙고(하늘빛 블루), 라이어(로즈 레드), 폭탄(웜 골드) 그라데이션 정의.
    - 다크 모드: 빙고(딥 네이비), 라이어(딥 크림슨), 폭탄(딥 브라운) 그라데이션 정의. `--bg-gradient` CSS 변수 오버라이드 방식으로 구현.
- **검증 결과**:
  - `node -c public/js/room.js` 구문 검사 통과.
  - 시나리오 검증:
    - 방장이 게임 카드(빙고/라이어/폭탄)를 클릭할 때마다 `body`에 해당 `lobby-theme-*` 클래스가 부여되어 배경이 0.85s 동안 부드럽게 전환됨.
    - 다른 게임 카드 클릭 시 이전 클래스를 제거하고 새 클래스를 부여하여 연속 전환 정상 동작.
    - 대기실 복귀 이벤트(`lobby`) 수신 시 모든 테마 클래스 제거, 기본 배경으로 복원.
    - 인게임 시작 시 `showContainer` 내부에서도 클리어 보장 (이중 방어).
    - 다크/라이트 모드 전환 시에도 CSS 우선순위(`body.dark-mode.lobby-theme-*`)에 의해 올바른 테마 색상 적용.
- **상태**: 완료 (2026-09-26)

### Task 3. 빙고 찬스 이벤트 팝업 글래스모피즘 리디자인
- **대상 파일**: `public/js/bingo.js`, `public/css/bingo.css` (또는 `common.css`)
- **배경 및 기획**:
  - 빙고 게임 중 발동하는 특수 찬스 이벤트 팝업이 초기 스타일로 남아 있어, 최근 개선된 다른 게임들의 모던 글래스모피즘 룩앤필과 시각적 이질감이 존재함.
- **작업 내용**:
  - **이벤트 팝업 전면 리디자인 (`public/css/bingo.css`)**:
    - `#big-event-display`: 순수 검정 오버레이 → 이벤트 타입별 `radial-gradient` 오버레이(레드/그린/블루/퍼플).
    - `.event-content`: `border: 6px solid white` 구식 틀 → 진짜 `backdrop-filter: blur(28px) saturate(1.6)` 글래스모피즘 카드. `box-shadow` 레이어링으로 글로우 효과.
    - 이벤트 타입별(bad/bomb/good/bonus/info) border/glow 테마 스타일 분리.
    - `.event-type-badge`: 타입별 문구 배지 스타일 정의.
    - `#event-icon`: 플로팅 애니메이션 + drop-shadow. `#event-title`: 타입별 글로우 텍스트 섀도.
    - `.pop-in`: `cubic-bezier(0.16, 1, 0.3, 1)` 스프링 애니메이션. 종료 시 `fading-out` 클래스 페이드아웃.
  - **이벤트 팝업 JS 리팩터링 (`public/js/bingo.js`)**:
    - `showBigEvent()` 함수에서 `content.style.borderColor` 인라인 스타일 제어 제거.
    - `overlay.classList`, `content.classList`에 `type-*` 클래스 동적 부여/제거.
    - 타입 배지(`event-type-badge`)를 `content.insertBefore`로 동적 삽입.
    - 3초 후 `fading-out` 클래스 추가 후 0.4초 뒤 `display: none` 정리(비주얼 종료 개선).
- **검증 결과**:
  - `node -c public/js/bingo.js` 구문 검사 통과.
  - 시나리오 검증:
    - 매 타입별(bad/bomb/good/bonus/info) 이벤트 호출 시 오버레이 색조, 카드 border, glow, 타이틀 색상이 새로운 테마에 맞게 일관 적용.
    - 이벤트 타입 배지(`행운 이벤트` 등) DOM에 동적 삽입 확인.
    - 연속 이벤트 호출 시 이전 타입 클래스 또는 배지가 잘못 남지 않도록 클린업 정상 동작.
    - 3초 동안 표시 후 `fading-out` 페이드 애니메이션 후 완전히 숨김.
- **상태**: 완료 (2026-09-26)
