## 1. 완료 항목 요약

### (1) 폭탄 아레나 플레이어 지목 번호 배지 추가
- **위치**: `public/js/bomb.js`, `public/css/bomb.css`
- **내용**:
  - 전략 모드에서 지목 편의성을 위해 플레이어 아바타 상단에 1~N번 번호 배지(`${playerNum}`) 부착.
  - 서버 `sortedPlayers` 정렬 순서와 100% 동기화하여 플레이어 간 번호 불일치 방지.
  - 지목 대상 선택 시 락온 애니메이션 테두리(`is-targeted`) 연동.
- **상태**: 완료 (2026-09-02)

### (2) 라이어 게임 본인 투표 오류 문구 정정
- **위치**: `sockets/liarSocket.js` (339줄)
- **내용**:
  - 투표 단계에서 본인 지목 시 발생하던 어색한 문구(`"자신의 힌트에는 투표할 수 없습니다!"`)를 직관적인 `"본인에게는 투표할 수 없습니다!"`로 정정.
- **상태**: 완료 (2026-09-02)

### (3) 라이어 게임 게스트 대기 안내 문구 보완
- **위치**: `public/js/liar.js` (812줄)
- **내용**:
  - 라운드 종료 후 게스트 화면에 노출되던 불필요한 장식 문구를 배제하고 `"방장이 다음 라운드를 준비하고 있습니다."`로 명확화.
- **상태**: 완료 (2026-09-02)

### (4) 방 입장 로딩 화면 비주얼 개선 및 프리뷰 토글 버튼 추가
- **위치**: `public/css/common.css`, `public/games/game.html`, `public/js/room.js`
- **내용**:
  - **애니메이션 강화 (C안)**: 로고 진입 페이드업(`loadingLogoIn`), 호흡 글로우 모션(`loadingLogoBreathe`), 3점 도트 펄스를 부드러운 cubic-bezier 웨이브로 개편, 방 진입 시 scale-up 페이드아웃 적용.
  - **단계별 동적 문구 피드백 (E안)**: 고정 문구 대신 단계별 동적 문구 피드백 연동 (`서버에 연결하는 중...` ➡️ `게임 환경을 준비하는 중...` ➡️ `입장 준비 완료!`).
  - **테스트용 프리뷰 버튼**: 대기실 채팅 헤더에 스피너 아이콘 토글 버튼(`#loading-preview-btn`) 배치. 클릭 시 2.3초간 로딩 오버레이 시연 후 자동 닫힘 (화면 클릭 시 즉시 닫힘 지원).
- **상태**: 완료 (2026-09-09)

### (5) 폭탄 돌리기 하트 렌더링 함수화 (리팩터링)
- **위치**: `public/js/bomb.js`
- **내용**:
  - 아레나 슬롯(`renderBombUsers`)과 스코어보드(`updateBombScoreboard`)에 중복 존재하던 하트 생성 반복문을 `getHeartsHtml(currentHearts, maxHearts)` 공통 헬퍼 함수로 통합.

- **상태**: 완료 (2026-09-09)

## 3. 종합 실측 검증 내역

- **구문 검사**: `node -c public/js/room.js`, `node -c public/js/bomb.js` 오류 없음 확인.
- **3인 멀티플레이 시뮬레이션 검증**:
  - 백그라운드 소켓 더미 봇 2대(`테스트봇1`, `테스트봇2`)를 방에 자동 접속시켜 단일 브라우저 세션 충돌을 우회한 3인 멀티플레이 환경 구축.
  - **전략 모드 지목 배지**: 아레나에 1, 2, 3번 배지가 서버 순번에 맞춰 100% 정상 출력됨 확인.
  - **타겟 락온**: 내 턴에서 플레이어 클릭 시 붉은색 락온 테두리(`is-targeted`) 정상 활성화 확인.
  - **하트 렌더링**: `❤️❤️❤️` 정상 출력 및 폭발 후 실시간 `❤️❤️🖤` 감소 반영 확인.
  - **로딩 토글 버튼**: 헤더 버튼 클릭 시 로딩 오버레이 팝업, 단계별 문구 출력, 화면 클릭 시 즉시 닫힘 정상 작동 확인.
