웹 브라우저 접속만으로 즐기는 실시간 멀티플레이 플랫폼.
01
왜 만들었나?
설치·로그인 장벽 없이 링크 하나로 바로 모여 즐길 수 있는 웹 파티 게임의 높은 수요에서 착안.
02
어떻게 동작하나?
방장이 방을 파고 링크를 공유하면 즉시 동시 입장. Socket.io 양방향 통신으로 모든 플레이 상태 동기화.
03
AI를 도입한 이유?
고정된 단어 풀의 한계를 깨고, 유저가 입력한 주제에 맞춰 Gemini API가 매판 무한한 단어를 생성.

개발 과정

도전 과제 & 해결 방법

실시간 멀티플레이 환경에서 직면한 4가지 핵심 난제 극복기

동시에 버튼을 눌렀을 때 판정이 꼬이는 현상
여러 플레이어가 0.1초 차이로 동시에 행동할 때, 누가 먼저인지 꼬이거나 결과가 달라지는 문제
해결 방법
모든 게임 판정을 중앙 서버의 하나의 기준으로 공정하게 처리하고, 모든 유저에게 동일한 결과를 실시간 전달
AI 단어 생성 대기 시간과 호출 비용 문제
인공지능에게 새 단어를 받아올 때 1~3초가 걸려 게임 진행 흐름이 끊기고 비용이 계속 발생하는 문제
해결 방법
한 번 만들어진 단어는 데이터베이스에 영구 저장해 다음엔 0초 만에 즉시 꺼내 쓰고, 연속 요청 방지 장치 구축
실수로 새로고침(F5)을 눌렀을 때 방이 터지는 현상
게임 도중 실수로 새로고침을 누르면 다른 사람으로 인식되어 강제로 쫓겨나거나 방이 깨지는 문제
해결 방법
브라우저에 고유 열쇠(ID)를 발급하여, 새로고침을 해도 원래 하던 게임 자리와 방장 권한을 100% 자동 복구
다크 / 라이트 모드 전환 시 화면 번쩍임
화면 모드를 바꿀 때 일부 색상이 늦게 따라와 화면이 어색하게 번쩍이고 눈이 피로한 잔상 발생
해결 방법
모든 화면 요소의 색상이 지연 없이 찰나에 한 번에 바뀌도록 설계하여, 잔상 없는 눈이 편안한 즉시 전환 구현
