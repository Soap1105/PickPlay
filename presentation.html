About
"설치 없이, 링크 하나로
친구들과 바로 게임을."
  • 🧩
    왜 만들었나?
    카카오게임 같은 브라우저 파티 게임을 직접 구현해보고 싶었습니다.
    별도 설치 없이 방 코드 하나로 즉시 접속, 실시간으로 함께 즐기는 게임을 목표로 했습니다.
  • 🌐
    어떻게 동작하나?
    방장이 방을 만들고 코드를 공유하면 플레이어들이 같은 방에 입장.
    서버가 모든 상태를 실시간으로 동기화해 함께 게임이 진행됩니다.
  • 🤖
    AI가 들어간 이유?
    빙고 주제 단어를 매번 사람이 만들면 한계가 있어 Gemini API를 연동.
    어떤 주제든 25~50개 단어를 자동 생성해 무한히 새로운 게임이 가능합니다.

Game 01
🟩

빙고 게임

AI가 만든 단어로 채우는 실시간 턴제 빙고

  • AI 주제 단어 자동 생성
    Gemini API가 주제에 맞는 단어 25~50개 생성, 5×5 빙고판 자동 배치
  • 실시간 순차 턴제
    플레이어가 순서대로 돌아가며 단어를 선택, 모두의 화면에 즉시 반영
  • 턴 타이머
    제한 시간 내 선택하지 않으면 자동으로 다음 플레이어로 턴 이동
  • 이벤트 카드 시스템
    빙고판 초기화, 단어 교환 등 특수 이벤트가 랜덤 발동해 게임에 변수 추가
  • 줄 완성 스탬프 애니메이션
    빙고 줄 완성 시 칸들이 순서대로 튀어오르는 타격감 있는 연출
  • 내 턴 시각 강조
    내 차례엔 빙고판이 초록 네온으로 빛나고 이름 칸이 노랗게 깜빡임
💡 핵심: DB 캐싱으로 이미 생성한 주제는 API 비용 없이 즉시 재사용  |  30초 쿨타임으로 API 남용 이중 방어
Game 02
🕵️

라이어 게임

제시어를 모르는 스파이를 찾아내는 소셜 추리 게임

🎮 게임 흐름

① 주제 공개 — 라이어만 제시어를 모른 채 시작
② 순차 발언 — 모두가 돌아가며 힌트 발언
③ 실시간 투표 — 라이어로 의심되는 사람에게 투표
④ 최후 변론 — 지목된 라이어의 마지막 해명 기회
⑤ 최종 결과 — 라이어 공개 & 승패 판정
  • 실시간 타이핑 동기화
    최후 변론 시 글자 한 자씩 다른 플레이어 화면에 실시간으로 나타나는 연출
  • 3단계 타이머
    초록 → 노랑 → 빨강 색상 전환으로 시간 압박감을 직관적으로 전달
  • 단계별 UI 자동 전환
    서버가 페이즈를 관리해 모든 플레이어 화면이 동시에 전환됨

Development

개발 도전 과제 & 해결

🤖 AI 어뷰징 방지
❌ 문제: 사용자가 "ㅋ" 같은 자음 입력 시 Gemini가 그대로 단어를 생성해버림. 연속 클릭 시 API 할당량 고갈.
→클라이언트 자음 정규식 차단 + 서버 30초 쿨타임 이중 방어 + DB 캐싱으로 재요청 방지
🔄 게임 재시작 타이밍 동기화
❌ 문제: 결과창을 확인 중인 유저가 있는데 방장이 게임을 재시작하면 해당 유저가 게임에 참여 불가.
→서버에서 confirmedResult 상태 관리, 모든 유저가 확인 완료해야 방장이 재시작 가능하도록 제어
⚡ 실시간 타이핑 동기화
❌ 문제: 최후 변론 타이핑을 실시간으로 보여주려면 글자 입력마다 전체 DOM을 재렌더하면 성능 저하.
→글자 추가 시 span만 추가하는 방식으로 DOM 재렌더 없이 최적화, 글자 낙하 애니메이션도 구현
🛡️ 쿨타임 시스템 설계
❌ 문제: 게임 중 대기방 이탈 후 재입장 시 쿨타임 UI가 초기화되어 우회 가능.
→서버 인메모리에 쿨타임 상태 보관, 재입장해도 남은 시간을 그대로 이어받아 적용
